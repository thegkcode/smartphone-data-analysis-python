# Smartphone Data Analysis Using Python

## Overview
This project focuses on cleaning and exploring a smartphone dataset using Python. It covers data quality assessment, preprocessing, feature extraction, exploratory data analysis, and data visualization to understand smartphone specifications and pricing patterns.

## Objectives
- Identify and handle data quality and consistency issues.
- Clean and transform smartphone specifications.
- Analyze smartphone brands, prices, ratings, and technical features.
- Visualize distributions and relationships between smartphone attributes.
- Explore correlations among numerical features.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Structure
- `01-smartphone-data-cleaning.ipynb` — Data quality assessment, cleaning, and preprocessing.
- `02-smartphone-eda.ipynb` — Exploratory analysis and data visualization.
- `data/` — Dataset files, where permitted.

## Analysis Areas
- Smartphone brand distribution
- Price and rating distributions
- RAM, storage, processor, and display specifications
- 5G, NFC, infrared, and fast-charging features
- Relationships between smartphone specifications and prices

## How to Run
1. Clone or download this repository.
2. Install the required Python libraries.
3. Update the dataset paths if necessary.
4. Run the data-cleaning notebook first.
5. Run the EDA notebook using the cleaned dataset.

Install dependencies:

```bash
pip install pandas numpy matplotlib seaborn jupyter
```
